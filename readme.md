# Aplicación Api de Ingresos/Gastos

## Aplicacion realizada con Fastapi y base de datos sqlite

# Utilizacion de libreria fastApi

Para poder utilizar la aplicación debe crear un entorno virtual
```
py -m venv entorno
```
lo activas
```
para windows .\entorno\Scripts\activate para mac o linux source /entorno/bin/activate
```
una vez creado el entorno y activarlo debes ejecutar este comando
```
pip install -r requirements.txt
```
